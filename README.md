# akaitiv

Учебный проект: веб-клон системы электронного зачетного книжки колледжа. Проект демонстрирует процесс реверс-инжиниринга интерфейса и миграцию стека технологий с оригинального решения на классический стек PHP + CSS.

## Описание проекта

Этот проект представляет собой попытку воссоздания функционала и интерфейса системы учета активностей (референс: kait-20.ru). Основная цель разработки заключалась в переносе логики с оригинального стека (Tailwind + Bash) на более классический и понятный для изучения стек: PHP для серверной части, чистый CSS для стилизации и HTML/JS для фронтенда. Проект служит практическим опытом работы с PHP-шаблонизацией и структурированием веб-приложений.

---

## Стек технологий

- **PHP** — серверная логика, подключение к базе данных и шаблонизация (header, footer, base)
- **HTML5** — семантическая разметка страниц
- **CSS3** — кастомная стилизация интерфейса без использования тяжелых фреймворков
- **JavaScript** — базовая клиентская интерактивность
- **SQL** — структура и начальные данные базы данных (см. `EXECUTE ME.sql`)

---

## Установка и запуск локально

Для работы проекта требуется локальный веб-сервер с поддержкой PHP и базой данных (например, OpenServer, XAMPP или Docker).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/akaitiv.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd akaitiv
   ```
3. Импортируйте структуру базы данных, выполнив SQL-скрипт EXECUTE ME.sql в вашей СУБД (например, через phpMyAdmin).
4. Настройте параметры подключения к базе данных в файле base.php (если требуется).
5. Запустите проект через локальный сервер и откройте index.php в браузере.

# Структура
```text
akaitiv/
 ├── index.php          # Главная страница приложения
 ├── base.php           # Файл конфигурации и подключения к базе данных
 ├── header.php         # Шаблоны верхней части страниц
 ├── footer.php         # Шаблоны нижней части страниц
 ├── activities/        # Модуль управления активностями/мероприятиями
 ├── groups/            # Модуль управления учебными группами
 ├── students/          # Модуль управления данными студентов
 ├── manage/            # Панель административного управления
 ├── give/              # Модуль выдачи оценок/зачетов
 ├── css/               # Директория с файлами стилей
 ├── EXECUTE ME.sql     # SQL-скрипт для создания и наполнения базы данных
 └── LICENSE            # Лицензия проекта (MIT)
```
